# Greedy Algorithm – Selection Sort in C++

## Simple C++ Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    int arr[5] = {64, 25, 12, 22, 11};

    for (int i = 0; i < 5; i++)
    {
        int min = i;

        for (int j = i + 1; j < 5; j++)
        {
            if (arr[j] < arr[min])
            {
                min = j;
            }
        }

        int temp = arr[i];
        arr[i] = arr[min];
        arr[min] = temp;
    }

    cout << "Sorted Array: ";

    for (int i = 0; i < 5; i++)
    {
        cout << arr[i] << " ";
    }

    return 0;
}
```

---

# Output

```text
Sorted Array: 11 12 22 25 64
```

# Simple Theory

Selection Sort is a Greedy Algorithm because:

* It selects the smallest element at every step.
* Places it in correct position.

Steps:

1. Find smallest element
2. Swap it
3. Repeat process
