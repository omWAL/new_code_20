# Simple A* Algorithm in C++

```cpp
#include <iostream>
#include <queue>
using namespace std;

struct Node
{
    int vertex;
    int cost;

    bool operator<(const Node &a) const
    {
        return cost > a.cost;
    }
};

int main()
{
    priority_queue<Node> pq;

    int heuristic[5] = {7, 6, 2, 1, 0};

    pq.push({0, heuristic[0]});

    while (!pq.empty())
    {
        Node current = pq.top();
        pq.pop();

        cout << current.vertex << " ";

        if (current.vertex == 4)
        {
            cout << "\nGoal Reached";
            break;
        }

        if (current.vertex == 0)
        {
            pq.push({1, 1 + heuristic[1]});
            pq.push({2, 4 + heuristic[2]});
        }

        if (current.vertex == 1)
        {
            pq.push({3, 2 + heuristic[3]});
        }

        if (current.vertex == 2)
        {
            pq.push({3, 1 + heuristic[3]});
        }

        if (current.vertex == 3)
        {
            pq.push({4, 3 + heuristic[4]});
        }
    }

    return 0;
}
```

---

# Simple Theory

A* algorithm is used to find shortest path.

It uses:

f(n)=g(n)+h(n)

Where:

* g(n) = actual cost
* h(n) = estimated cost
* f(n) = total cost

Used in:

* Games
* Maps
* Navigation
* AI searching
