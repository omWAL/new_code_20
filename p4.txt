# N-Queens Problem using Backtracking

## Simple C++ Code

```cpp id="5m7onq"
#include <iostream>
using namespace std;

int board[10];

bool safe(int row, int col)
{
    for (int i = 0; i < row; i++)
    {
        if (board[i] == col || abs(board[i] - col) == abs(i - row))
        {
            return false;
        }
    }

    return true;
}

void queen(int row, int n)
{
    if (row == n)
    {
        for (int i = 0; i < n; i++)
        {
            cout << board[i] << " ";
        }

        cout << endl;
        return;
    }

    for (int col = 0; col < n; col++)
    {
        if (safe(row, col))
        {
            board[row] = col;
            queen(row + 1, n);
        }
    }
}

int main()
{
    int n = 4;

    queen(0, n);

    return 0;
}
```

# Simple Theory

## N-Queens Problem

Place N queens on chessboard so that:

* No two queens attack each other

Queens attack:

* Same row
* Same column
* Same diagonal

---

# Backtracking

Backtracking works by:

1. Place queen
2. Check safe position
3. Move forward
4. If conflict occurs, go back and try another position
