# Expert System for Information Management in C++

## Simple C++ Code

```cpp id="8t8gxv"
#include <iostream>
#include <string>
using namespace std;

int main()
{
    int choice;
    string name;

    while (true)
    {
        cout << "\n1. Student Info";
        cout << "\n2. Teacher Info";
        cout << "\n3. Exit";
        cout << "\nEnter choice: ";
        cin >> choice;

        if (choice == 1)
        {
            cout << "Enter student name: ";
            cin >> name;

            cout << "Student Name: " << name;
            cout << "\nCourse: Computer Engineering";
        }

        else if (choice == 2)
        {
            cout << "Enter teacher name: ";
            cin >> name;

            cout << "Teacher Name: " << name;
            cout << "\nDepartment: IT";
        }

        else if (choice == 3)
        {
            cout << "Program Ended";
            break;
        }

        else
        {
            cout << "Invalid Choice";
        }
    }

    return 0;
}
```

# Simple Theory

## Expert System

An Expert System is an AI program that gives decisions or information like a human expert.
